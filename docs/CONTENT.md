# SOBRE

## Texto

#### O que é a BraynGames?

A BraynGames é um estúdio independente focado no desenvolvimento de jogos em pixel art. O objetivo é criar experiências acessíveis, divertidas e cuidadosamente planejadas, valorizando mecânicas sólidas e projetos com escopo bem definido.

#### Quem está por trás?

A BraynGames é um projeto solo. Atualmente, todos os jogos são desenvolvidos por uma única pessoa, responsável pela programação, design das mecânicas, arte, interface, testes e publicação.

#### O que você encontrará aqui?

Neste site você poderá acompanhar os jogos desenvolvidos pela BraynGames, conhecer projetos em desenvolvimento, acompanhar novidades através do Devlog e encontrar os links oficiais para cada plataforma.

#### Nossa filosofia

Cada jogo nasce da vontade de explorar novas ideias sem perder o foco em terminar aquilo que foi iniciado. A BraynGames acredita que bons jogos são construídos passo a passo. Cada projeto é uma oportunidade de experimentar novas ideias, aprender durante o desenvolvimento e continuar evoluindo após o lançamento.

#### Nossos princípios

Na BraynGames, cada projeto é guiado por alguns princípios:
- Jogos completos antes de jogos gigantes.
- Mecânicas simples, mas bem executadas.
- Escopo realista e desenvolvimento consistente.
- Pixel art como identidade visual.
- Aprendizado contínuo a cada projeto.
- Transparência no processo de desenvolvimento.

#### Texto fim

Cada novo projeto representa uma oportunidade de aprender, experimentar novas ideias e transformar esse aprendizado em jogos melhores.
