# BraynGames Site

Site institucional oficial da BraynGames, desenvolvido para apresentar o estúdio, seus jogos, o processo de desenvolvimento e centralizar os links oficiais da marca em um único lugar.


# Objetivo

Criar um site simples, moderno e organizado que represente a identidade da BraynGames, facilite o acesso aos seus projetos e registre a evolução do desenvolvimento através do Devlog.

Além do código-fonte, este repositório também reúne toda a documentação utilizada durante o planejamento e desenvolvimento do projeto.


# Status do Projeto

Em desenvolvimento.

Atualmente o projeto encontra-se na fase de planejamento e documentação antes do início da implementação em HTML, CSS e JavaScript.
